# Task-2-API-framework
Consuming an API using front end framework

Description:
This project demonstrates how to consume the JSONPlaceholder API (https://jsonplaceholder.typicode.com) using a frontend framework. 
It includes:
Fetching data from the API.
Performing CRUD (Create, Retrieve, Update, Delete) operations.
Pagination and state management.
Responsive design and caching for optimization.

Key Features:
Built using a frontend framework (e.g., React, Vue.js).
Pagination and sorting for better user experience.
Optimized for performance.
